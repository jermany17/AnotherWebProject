## Another Recipe: 나만의 요리 레시피 공유 서비스

사용자가 게시물 형태로 자신만의 요리 레시피를 등록하고, 다른 사용자와 공유할 수 있는 웹 애플리케이션

### 역할
Backend  

### 사용 기술  
Java, Spring Boot, MySQL, AWS RDS, AWS S3, Docker, EC2, GitHub Actions  

### 구현 기능  
- 사용자 인증 기능  
- 레시피 및 리뷰 관련 CRUD 기능
